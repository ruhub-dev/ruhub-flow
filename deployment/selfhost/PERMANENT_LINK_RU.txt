RUHUB FLOW — ПОСТОЯННЫЙ АДРЕС В БРАУЗЕРЕ

https://ruhub-dev.github.io/ruhub-flow/

Интерфейс редактора загружается с GitHub Pages и остаётся по этому адресу.
Аккаунты, пароли, схемы, история и резервные копии хранятся на вашем ПК.
GitHub хранит исходники интерфейса и публичный адрес подключения к серверу.
Новые ссылки «Поделиться» также используют постоянный GitHub-адрес.
Секретные ключи схем находятся после # и не отправляются при загрузке GitHub.

КАК ОБНОВИТЬ
1. Остановите сервер Ctrl+C.
2. Полностью распакуйте архив обновления в отдельную папку.
3. Запустите INSTALL_UPDATE.cmd и выберите рабочую папку RUHUB-Flow.
4. Запустите обычный START_INTERNET.cmd.
5. Дождитесь «ПОСТОЯННАЯ ССЫЛКА» и откройте адрес GitHub выше.
При первом переходе войдите в кабинет прежним логином/email и паролем.
Впоследствии сессия остаётся привязанной к постоянному адресу GitHub,
а не к меняющемуся имени туннеля. Срок действия сессии — семь дней.

База data, резервные копии и существующий ключ GitHub не перезаписываются.
Предыдущие файлы программы сохраняются в updates\before-stable-link-....
Если ключ уже настроен, повторная настройка не нужна.

КАК ЭТО РАБОТАЕТ
• При запуске программа ждёт подтверждения подключения cloudflared.
• Через Windows PowerShell она обновляет connection/current.json в GitHub.
• Интерфейс GitHub регулярно проверяет этот файл и обращается к текущему
  серверу. При смене адреса туннеля вкладка не перенаправляется.
• Внешние запросы API разрешены только с https://ruhub-dev.github.io.
  Пароли, серверные сессии и права на схемы проверяются как прежде.
• Компьютер должен оставаться включённым и подключённым к интернету.
  При отключении отображается состояние отсутствия связи; очередь правок
  в открытом редакторе остаётся в браузере до возобновления связи.

ОДНОКРАТНАЯ НАСТРОЙКА GITHUB, ЕСЛИ ЕЩЁ НЕ ВЫПОЛНЕНА
SETUP_GITHUB.cmd -> существующий аккаунт ruhub-dev -> fine-grained token:
Repository access: Only select repositories -> ruhub-flow.
Repository permissions: Contents -> Read and write.
Ключ вставляется только в окно настройки на вашем компьютере.
Он хранится в data\github-token.dpapi с шифрованием Windows.
В чат, публичные файлы и письма его не отправляйте.
При истечении/отзыве ключа повторите SETUP_GITHUB.cmd.

ДИАГНОСТИКА
Сообщения туннеля: logs\tunnel.log.
Ошибки обновления адреса: logs\link-update.log.
Ошибки DNS, HTTPS, тайм-ауты и HTTP-коды показываются без секретного ключа.
Если сервер в порядке, но GitHub-страница пока показывает отсутствие связи,
после установки обновления нажмите «Повторить» или обновите вкладку.
Ранее выданные прямые trycloudflare-ссылки могут устареть; выдайте новые
через «Поделиться» при работе на постоянном адресе GitHub.

Тема и пользовательские шаблоны — локальные настройки браузера.
Устройства и их порты, сохранённые внутри схем, находятся в базе на ПК.
START_LOCAL.cmd и BACKUP.cmd продолжают работать как прежде.
