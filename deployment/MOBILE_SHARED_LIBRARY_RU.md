# RUHUB Flow 3.1

На смартфоне и планшете панели открываются кнопками «Устройства», «Параметры» и «Меню» внизу экрана. Устройство добавляется перетаскиванием на полотно или отдельной кнопкой «Добавить на схему» в библиотеке. Нажатие на название или карточку не добавляет устройство. Выбранный объект можно приблизить кнопкой на полотне.

Два пальца перемещают и масштабируют полотно. Одним пальцем можно двигать устройства и кабели; инструмент «Рука» перемещает полотно поверх объектов. Размер устройства меняется за нижний правый угол или числовыми полями в параметрах.

Для точного подключения выберите устройство → «Параметры» → «Подключить кабель» и укажите порты в списках. Для переноса выберите кабель и нажмите «Изменить источник» или «Изменить назначение». Перетаскивание и подключение последовательным нажатием портов тоже доступны. Стили, изгибы и цвета кабелей доступны в параметрах. Подтверждение переноса отключается в меню.

## Общая библиотека

После входа все участники видят одну библиотеку на вашем сервере. Редактировать её может владелец или редактор открытой схемы; зритель может просматривать. Изменения появляются у других участников примерно за пять секунд. Одновременное сохранение устаревшей версии отклоняется: откройте конфигурацию заново.

Изменение шаблона влияет на следующие добавления устройств. Уже размещённые устройства сохраняют свою конфигурацию. По желанию при сохранении шаблона можно применить изменения к таким же устройствам в текущей схеме.

Прежние шаблоны из конкретного браузера можно перенести кнопкой «Опубликовать мои шаблоны». Уже изменённые общие шаблоны при этом не перезаписываются. Нажмите эту кнопку в том браузере, где создавали свои устройства.

## Соединения

Один физический выход и один вход допускают по одному кабелю. Тип сигнала, направление и разъём должны совпадать. Разветвление выполняется через распределитель с отдельными выходами. Проверки работают и в интерфейсе, и на сервере, включая импорт и одновременные изменения.

Ранее созданные разветвления не удаляются автоматически. Пункт «Проверить соединения» показывает проблемные кабели: выберите кабель и перенесите его на свободный выход либо удалите. Исправлять можно постепенно.

## Установка на компьютер-сервер

1. Остановите приложение сочетанием Ctrl+C в окне START_INTERNET.cmd.
2. Распакуйте весь архив обновления. Запустите INSTALL_UPDATE.cmd и выберите вашу рабочую папку RUHUB-Flow.
3. Запустите START_INTERNET.cmd. Дополнительная таблица библиотеки создастся автоматически. Аккаунты и схемы сохранятся; прежние файлы программы останутся в updates.
4. Обновите страницу https://ruhub-dev.github.io/ruhub-flow/ на всех устройствах. Если осталась старая версия, закройте вкладку и откройте ссылку снова.

Для общей библиотеки и серверных проверок обязательно установить это обновление на компьютер. Один лишь новый интерфейс GitHub не обновляет сервер на вашем ПК.

## Удаление схем

Вернитесь в личный кабинет кнопкой возле логотипа. Под каждой карточкой проекта есть «Удалить схему» для владельца или «Убрать из кабинета» для приглашённого участника.

Владелец подтверждает «Удалить для всех»: проект, история и ссылки удаляются для всех участников. Отмены в приложении нет. Общая библиотека устройств сохраняется. Приглашённый участник убирает только карточку из своего кабинета и может снова открыть схему по ссылке.

## Подключение и скорость

При открытии приглашения убраны повторные проверки сервера и предварительное сохранение ссылки в кабинет. Схема открывается сразу после проверки аккаунта; ссылка сохраняется в кабинет в фоне после успешного открытия.

Медленные запросы синхронизации больше не накапливаются. Если схема не изменилась, сервер передаёт только номер версии, права доступа и присутствие участников. Большие схемы и общая библиотека передаются со сжатием. Зависший запрос завершается сообщением об ошибке; запросы входа и создания проекта автоматически не повторяются. Изменения схемы остаются в очереди на устройстве для следующей синхронизации.

Для сжатия и коротких ответов синхронизации установите это обновление на компьютер-сервер обычным INSTALL_UPDATE.cmd. После запуска сервера всем участникам нужно обновить страницу.

## Плавность редактора (3.1.1)

Расчёт портов и кабелей кэшируется. При перетаскивании обновляются только изменившиеся объекты, библиотека устройств повторно не строится. Движения мыши и касаний обрабатываются не чаще одного раза за кадр; последняя позиция применяется перед отпусканием. Проверка ошибок соединений запускается при открытии соответствующего окна.

Для этой правки на GitHub достаточно обновить страницу Ctrl+F5. Устанавливать серверное обновление поверх 3.1 не требуется.
